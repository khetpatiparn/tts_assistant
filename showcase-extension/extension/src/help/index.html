วิธีใช้ Showcase Scanner

extension นี้อ่านรายการสินค้าใน Showcase ของบัญชี TikTok ที่คุณล็อกอินอยู่ แล้วส่งไปที่ ลิงก์ปลายทาง — คือ "ที่อยู่" ของระบบที่จะรับสินค้า เช่น Google Sheets หรือเว็บของคุณเอง

Showcase ใน TikTok → Showcase Scanner → ลิงก์ปลายทาง → ระบบของคุณ

มีลิงก์ปลายทางแล้ว

  1. ล็อกอิน TikTok Shop ไว้ในเบราว์เซอร์นี้
  2. กดปุ่มด้านล่าง → ส่วน ตั้งค่า → วางลิงก์ในช่อง ลิงก์ปลายทาง → กด บันทึกลิงก์
  3. กดไอคอน Showcase Scanner บนแถบเครื่องมือ ถ้าไฟเป็นสีเขียว (หรือสีเทาที่บอกว่าส่งได้) พร้อมใช้งาน
  4. กด สแกนสินค้าใหม่ → ส่งไปปลายทาง ทุกครั้งที่เพิ่มสินค้าใน Showcase

ยังไม่มีลิงก์ — อยากเชื่อมกับระบบของคุณเอง

ระบบของคุณต้องมี "ลิงก์" หนึ่งอันที่รับสินค้าได้ เลือกทางที่ง่ายสำหรับคุณ

ทางที่ 1 — ให้ AI สร้างให้ (ไม่ต้องเขียนโค้ดเอง)

  1. กดปุ่ม คัดลอกคู่มือไปให้ AI ด้านล่าง
  2. วางในแชทของ AI ผู้ช่วยเขียนโค้ด (เช่น Claude, ChatGPT, Cursor) แล้วแก้บรรทัดแรกให้บอกว่าระบบของคุณคืออะไร
  3. AI จะสร้างส่วนรับสินค้าและบอกลิงก์ให้ → เอาลิงก์มาทำตามหัวข้อ "มีลิงก์ปลายทางแล้ว"

ทางที่ 2 — เขียนโค้ดเอง (ลองได้ใน 5 นาที)

ลิงก์ของคุณต้องรับคำขอ 2 แบบ:

คำขอextension ส่งมาคุณตอบ
POST (บังคับ) ข้อความ JSON {"products":[{"productId":"…","title":"…",…}]} เก็บสินค้าด้วย productId แล้วตอบ 200
GET (แนะนำ) — รายการ productId ที่มีแล้ว (ทำให้หยุดสแกนเองได้ + ไฟเขียว)

ลิงก์มีรหัสลับ ?token=… — token ไม่ตรงให้ตอบ 401 · ทุกคำตอบต้องมี header Access-Control-Allow-Origin: *

  1. ดาวน์โหลดไฟล์ตัวอย่างด้านล่าง (ต้องมี Node 18 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม)
  2. รัน node quickstart-node.mjs — โปรแกรมจะพิมพ์ลิงก์ออกมา
  3. เอาลิงก์ไปวางตามหัวข้อ "มีลิงก์ปลายทางแล้ว" → กดสแกน → สินค้าจะเข้ามาที่โปรแกรมของคุณ
  4. เปลี่ยนสองจุดในโค้ดที่เขียนว่า "ฐานข้อมูลของคุณ" ให้เป็นที่เก็บจริง
กำลังโหลด…
