# วิธีติดตั้ง Showcase Scanner

Showcase Scanner เป็นส่วนเสริม (extension) ของเบราว์เซอร์ ช่วยอ่านรายการสินค้าจากหน้า Showcase ของบัญชี TikTok Shop ของคุณเอง แล้วส่งไปยังระบบของคุณ (เช่น Google Sheets) ใช้ได้กับ Brave และ Chrome

## ติดตั้งครั้งแรก

1. แตกไฟล์ zip ที่ได้รับ (คลิกขวา > Extract All / แตกไฟล์) จะได้โฟลเดอร์ชื่อ `showcase-scanner-<เวอร์ชัน>` เก็บไว้ที่ถาวร เช่น `Documents` — **อย่าลบโฟลเดอร์นี้** เพราะเบราว์เซอร์อ่านตัว extension จากตรงนี้ตลอด
2. เปิดเบราว์เซอร์ แล้วพิมพ์ในช่องที่อยู่:
   - Brave: `brave://extensions`
   - Chrome: `chrome://extensions`
3. เปิดสวิตช์ **Developer mode** (โหมดนักพัฒนาซอฟต์แวร์) ที่มุมขวาบน
4. กดปุ่ม **Load unpacked** (โหลดส่วนขยายที่ยังไม่ได้แพ็ก) แล้วเลือก**โฟลเดอร์ที่แตกไว้ในข้อ 1 ได้เลย** (ข้างในต้องเห็นไฟล์ `manifest.json` ทันที) — ถ้าขึ้น "Manifest file is missing" แปลว่าเลือกโฟลเดอร์ชั้นนอกเกินไป ให้เข้าไปอีกชั้นจนเจอโฟลเดอร์ที่มี `manifest.json`
5. **ล็อกอิน TikTok Shop ในเบราว์เซอร์ตัวเดียวกันนี้** (ต้องล็อกอินค้างไว้ในเบราว์เซอร์/โปรไฟล์เดียวกับที่ติดตั้ง extension)
6. กดไอคอนจิ๊กซอว์ (Extensions) บนแถบเครื่องมือ แล้วกดปักหมุด Showcase Scanner เพื่อให้เห็นไอคอน
7. กดไอคอน Showcase Scanner แล้วกดเปิด **หน้าจัดการ**
8. ในหน้าจัดการ กดหัวข้อ **ตั้งค่า** เพื่อกางออก วาง **ลิงก์ปลายทาง** ที่ได้จากคนที่ดูแลระบบปลายทางของคุณ (ต้องเป็นลิงก์ทั้งบรรทัด) แล้วกด **บันทึกลิงก์**
9. กลับไปกดไอคอนอีกครั้ง ถ้าไฟเป็นสีเขียว (หรือสีเทาที่ขึ้นว่าส่งได้) แปลว่าพร้อมใช้งาน ถ้าเป็นสีแดงให้เช็กลิงก์อีกครั้ง

## อัปเดตเป็นเวอร์ชันใหม่

1. แตกไฟล์ zip เวอร์ชันใหม่ **ทับโฟลเดอร์เดิม** (เลือกแทนที่ไฟล์ทั้งหมด)
2. ไปที่ `brave://extensions` (หรือ `chrome://extensions`) แล้วกดปุ่มลูกศรวน (↻ โหลดใหม่) ที่การ์ดของ Showcase Scanner
3. ลิงก์ปลายทางและความจำว่าเคยส่งสินค้าอะไรไปแล้วจะยังอยู่ ไม่ต้องตั้งค่าใหม่

## ส่งไปหลายปลายทาง

extension ตัวหนึ่งส่งได้ปลายทางเดียว ถ้าต้องการส่งไปหลายที่ ให้ใช้ **โปรไฟล์เบราว์เซอร์แยกกัน** (แต่ละโปรไฟล์ติดตั้ง extension เองและใส่ลิงก์ของตัวเอง) — ต้องล็อกอิน TikTok Shop ในแต่ละโปรไฟล์ด้วย

## ถ้ายังไม่มีระบบปลายทางของตัวเอง

ดูโฟลเดอร์ `developer` (อยู่ข้างในโฟลเดอร์เดียวกับไฟล์นี้) — ถ้าเขียนโค้ดเป็น อ่านหัวข้อ "เริ่มใน 5 นาที" บนสุดของ `developer/INTEGRATION.md` ถ้าไม่เขียนโค้ด ส่งไฟล์นั้นให้ AI ผู้ช่วยเขียนโค้ด (เช่น Claude Code, Cursor) แล้วบอกว่าอยากได้ปลายทางแบบไหน (Google Sheets, เว็บของตัวเอง ฯลฯ) มีโค้ดตัวอย่างในโฟลเดอร์ `developer/examples` เมื่อได้ลิงก์แล้วก็วางในขั้นตอนที่ 8

## ข้อควรรู้

- extension อ่านเฉพาะ Showcase ของบัญชีที่คุณล็อกอินอยู่ และสแกนเมื่อคุณกดเท่านั้น
- ลิงก์ปลายทางเป็นเหมือนรหัสผ่าน อย่าส่งต่อหรือโพสต์ในที่สาธารณะ ถ้าลิงก์หลุด ให้ขอสร้างลิงก์ใหม่จากระบบปลายทาง แล้ววางลิงก์ใหม่แทน
- ถ้า popup ขึ้น "ยังไม่ได้ใส่ลิงก์ปลายทาง" ให้ทำตามขั้นตอนที่ 7-8
