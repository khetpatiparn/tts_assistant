# M1.5 — E2E harness, UAT และ G1 sign-off Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ปิด G1 ให้จบอย่างซื่อสัตย์ — แปลงการทดสอบด้วยมือเป็น automated E2E, วัด coverage จริง, และเขียน sign-off ที่ระบุชัดว่าอะไรผ่าน อะไรไม่ผ่าน

**Architecture:** เพิ่ม Playwright E2E layer แยกจาก vitest โดยสิ้นเชิง (คนละ config, คนละ npm script) เพื่อไม่ให้ browser download ของ Playwright ชนกับ network deny-by-default guard ของ vitest. E2E ทดสอบ `dist/` (mock channel) ที่ build แล้วเท่านั้น ไม่แตะ source โดยตรง. งานที่เหลือเป็น instrumentation (coverage), การขยาย static scan ที่มีอยู่, และเอกสาร

**Tech Stack:** Playwright (`@playwright/test`) · `@vitest/coverage-v8` · TypeScript strict · esbuild (มีอยู่แล้ว)

**Spec:** [docs/superpowers/specs/2026-09-19-m1.5-uat-e2e-design.md](../specs/2026-09-19-m1.5-uat-e2e-design.md)

## Global Constraints

- **`npm test` ต้องยังเป็น vitest อย่างเดียว** — Playwright แยกเป็น `npm run test:e2e` เพราะ `playwright install` ต้องโหลด browser ผ่าน network ซึ่งขัดกับ R15
- **ห้ามแก้ `tests/setup/no-network.ts`** — guard นี้คือหลักฐานของ R15 การแก้ต้องมีเหตุผลที่บันทึกไว้
- **E2E ทดสอบ `dist/` (mock channel) เท่านั้น** — release channel ไม่มี adapter ให้สแกน
- **ห้ามชี้ automation ไปยัง browser profile หลักของผู้ใช้** (spec §13.1) — ใช้ Chromium ที่ Playwright โหลดมาเอง
- **ห้ามใช้ `page.route` ดัก request ของ service worker** (spec §13.1 เตือนว่าดักไม่ครบ) — ใช้ `context.on('request')`
- **G0 ยังไม่ผ่าน** — ห้ามสร้าง live adapter, ห้ามแตะ TikTok จริง, ห้ามเติมค่าลง `VERIFIED_STOCK_STATUS` / `VERIFIED_REVIEW_STATUS` / `APPROVED_IMAGE_HOSTS`
- **ห้ามสร้าง permission gating** — UI06 ถูกเลื่อนออกไปโดยเจตนา (ดู spec §2.2)
- **สถานะ test ใช้ได้เฉพาะ** `NOT RUN` / `PASS` / `FAIL` / `BLOCKED` / `NOT APPLICABLE`
- **ห้ามเขียน PASS ถ้ายังไม่ได้รันจริง** — ทุกตัวเลขในเอกสารต้องมาจาก output จริงที่รันแล้ว
- **coverage ไม่แทน semantic validation** — ถ้าไม่ถึง 90% ให้เพิ่ม test ห้ามลดเกณฑ์

import { test as base, chromium, type BrowserContext } from '@playwright/test'
import { dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'

const HERE = dirname(fileURLToPath(import.meta.url))
/** E2E ทดสอบ mock channel เท่านั้น — release channel ไม่มี adapter ให้สแกน */
const EXTENSION_PATH = resolve(HERE, '../../../dist')

export const test = base.extend<{ context: BrowserContext; extensionId: string }>({
  // eslint-disable-next-line no-empty-pattern
  context: async ({}, use) => {
    // persistent context เท่านั้นที่โหลด extension ได้ และเป็น profile ชั่วคราวของ Playwright เอง
    // ไม่ใช่ profile หลักของผู้ใช้ (spec §13.1)
    const context = await chromium.launchPersistentContext('', {
      channel: 'chromium',
      args: [
        `--disable-extensions-except=${EXTENSION_PATH}`,
        `--load-extension=${EXTENSION_PATH}`,
      ],
    })
    await use(context)
    await context.close()
  },
  extensionId: async ({ context }, use) => {
    let [worker] = context.serviceWorkers()
    worker ??= await context.waitForEvent('serviceworker')
    // URL เป็น chrome-extension://<id>/background.js
    const extensionId = worker.url().split('/')[2] ?? ''
    await use(extensionId)
  },
})

export const expect = test.expect
```

import { test, expect } from './fixtures/extension.js'

test('Start → scan → select → export ครบวงจรในเบราว์เซอร์จริง', async ({ context, extensionId }) => {
  const page = await context.newPage()
  await page.goto(`chrome-extension://${extensionId}/dashboard/index.html`)

  await expect(page.locator('#start-button')).toBeVisible()
  await page.locator('#start-button').click()

  // สแกนจบแล้ว preview จะโผล่ (mock 20 ตัว, หน่วงหน้าละ 1 วินาที)

  await expect(page.locator('#run-status')).toContainText('ready_complete')

  // ทุกตัวเป็น unknown จึงอยู่แท็บ Other status
  await expect(page.locator('#count-other')).toHaveText('20')
  await expect(page.locator('#count-candidate')).toHaveText('0')

  await page.locator('.tab-button[data-filter="other"]').click()
  const checkboxes = page.locator('#product-list input[type=checkbox]')
  await expect(checkboxes).toHaveCount(20)

  await checkboxes.nth(0).check()
  await checkboxes.nth(1).check()
  await expect(page.locator('#selected-count')).toContainText('เลือกทั้งหมด: 2')

  const downloadPromise = page.waitForEvent('download')
  await page.locator('#export-button').click()
  const download = await downloadPromise

  const filePath = await download.path()
  expect(filePath).not.toBeNull()
  const payload = JSON.parse(await readFile(filePath as string, 'utf8')) as {
    selectedProductIds: string[]
    products: { productId: string }[]
    scanCoverage: string
    adapterVersion: string
  }

  expect(payload.selectedProductIds).toHaveLength(2)
  expect(payload.products).toHaveLength(2)
  expect(payload.products.map((p) => p.productId)).toEqual(payload.selectedProductIds)
  expect(payload.scanCoverage).toBe('reached_endpoint_end')
  expect(payload.adapterVersion).toBe('mock-v0')

import { test, expect } from './fixtures/extension.js'

test('PK04 — ทั้ง flow ไม่มี request ออกนอกเครื่องแม้แต่ครั้งเดียว', async ({ context, extensionId }) => {
  const externalRequests: string[] = []
  context.on('request', (request) => {
    const url = request.url()
    // chrome-extension:// และ devtools:// เป็นของภายใน; http(s) ที่ไม่ใช่ loopback คือออกนอกเครื่อง
    if (!/^https?:\/\//.test(url)) return
    if (/^https?:\/\/(127\.0\.0\.1|localhost)([:/]|$)/.test(url)) return
    externalRequests.push(url)
  })

  const page = await context.newPage()
  await page.goto(`chrome-extension://${extensionId}/dashboard/index.html`)
  await page.locator('#start-button').click()
  await expect(page.locator('#preview-section')).toBeVisible({ timeout: 30_000 })

  await page.locator('.tab-button[data-filter="other"]').click()
  await page.locator('#select-all-button').click()

  const downloadPromise = page.waitForEvent('download')
  await page.locator('#export-button').click()
  await downloadPromise

  expect(externalRequests).toEqual([])
})

test('PK04 — ไม่มี request ไปยัง tiktok host ใด ๆ', async ({ context, extensionId }) => {
  const tiktokRequests: string[] = []
  context.on('request', (request) => {
    if (request.url().includes('tiktok')) tiktokRequests.push(request.url())
  })

  const page = await context.newPage()
  await page.goto(`chrome-extension://${extensionId}/dashboard/index.html`)
  await page.locator('#start-button').click()
  await expect(page.locator('#preview-section')).toBeVisible({ timeout: 30_000 })

  expect(tiktokRequests).toEqual([])
})
```
