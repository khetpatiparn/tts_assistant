# Backlog — automation / ความเร็ว / การเปิดระบบ

จากการคุย grilling 2026-09-28 (คำศัพท์ดู `CONTEXT.md`) — จดไว้ก่อน ยังไม่เริ่มทำ รอผู้ใช้ให้สัญญาณ

## เป้าหมายที่ตกลงกันแล้ว

- ลงคลิปได้ **3-5 คลิป/วัน** · **1 คลิป = 1 สินค้าใหม่**
- ยอมใช้เวลา setup รวม **1-2 ชั่วโมง/วัน** แต่ต้องเป็นแบบคิว: ตั้งงานไว้แล้วไปทำอย่างอื่น แล้วค่อยกลับมาที่ Checkpoint
- ตัวชี้วัดคือ **ลด Attended time (เวลาที่ต้องนั่งเฝ้า)** ไม่ใช่ลดเวลารวม — ทำเองแบบ manual เร็วกว่าคิว แต่ต้องนั่งเฝ้า ทำอย่างอื่นไม่ได้
- กลับมาตัดสินใจแค่ **1-2 รอบ/วัน** แล้วเคลียร์ Checkpoint ที่ค้างทั้งหมดในรวดเดียว (บอทต้องไม่นั่งรอระหว่างนั้น)
- **เลือกสินค้ายังทำเองเสมอ** — เป็นวิจารณญาณที่มีผลต่อรายได้จริง ระบบช่วยได้แค่เรียง/กรอง
- ลำดับความสำคัญ: **C (เปิดระบบ) → B (ความเร็ว) → A (automation)**
