# ลิงก์ปลายทางฝังรหัสไว้ใน URL แทน header หรือการเซ็นลายเซ็น

Showcase Scanner ต้องส่งผลสแกนเข้าระบบของคนที่เราไม่รู้จักโครงสร้าง (Google Apps Script, n8n, โค้ดที่ AI เขียน) และผู้ใช้ต้องตั้งค่าได้เองในขั้นตอนเดียว เราเลือกให้ปลายทางออก "ลิงก์ลับ" หนึ่งอันที่มีรหัสอยู่ใน query string (แบบ webhook ของ Discord/Slack/Google Chat) ผู้ใช้วางลิงก์เดียวจบ

**ทางเลือกที่ไม่เลือก:** (1) รหัสใน header `x-showcase-secret` แบบเดิม — Google Apps Script อ่าน request header ไม่ได้ และทำให้ผู้ใช้ต้องกรอก 2 ช่อง (2) HMAC ลงลายเซ็นทุก payload แบบ Stripe/GitHub — รหัสไม่ถูกส่งออกไปเลยจึงปลอดภัยกว่า แต่ปลายทางทุกเจ้าต้องเขียนโค้ดตรวจลายเซ็น (ทำใน Apps Script ยาก) เกินความจำเป็นสำหรับข้อมูลสินค้าที่เปิดดูได้บน Showcase อยู่แล้ว (3) ตรวจ `Origin` ของ extension — ใช้ไม่ได้เพราะแจกแบบ zip/Load unpacked ทำให้ ID ของ extension ต่างกันทุกเครื่อง

**ผลที่ยอมรับ:** ลิงก์หลุดง่ายกว่า header (ติดไปกับ log/แคปหน้าจอ/แชท) และใครได้ลิงก์ก็ส่งเข้าได้เต็มสิทธิ์ — ชดเชยด้วยปุ่ม "สร้างลิงก์ใหม่" ที่ทำให้ลิงก์เก่าใช้ไม่ได้ทันที และบังคับ https สำหรับปลายทางที่ไม่ใช่ localhost
