# บอทคุมหน้าเว็บ Google Flow จริงด้วย Chrome ที่มองเห็นได้ บนบัญชีสำรอง — ไม่ใช้ API

การวาดรูปอ้างอิงและเรนเดอร์คลิปทำผ่านหน้าเว็บ Flow ด้วย Playwright + Chrome จริง (headed, โปรไฟล์ `.flow-profile`) บน**บัญชี Google สำรอง** ไม่ใช่บัญชีหลัก Ultra ของผู้ใช้ เพราะเครดิต Flow ผ่านหน้าเว็บถูกกว่าทุกทาง API ราว 6–8 เท่า (~15 เครดิต/คลิป) และผู้ใช้ตัดสินใจชัดว่าไม่ใช้ API (2026-09-30) ส่วนบัญชีสำรองจำกัดความเสียหายถ้าโดนจับว่าเป็นบอท

**ทางเลือกที่ไม่เลือก:** (1) API วิดีโอ/รูปที่จ่ายต่อครั้ง — แพงกว่ามาก (2) ยิง RPC `batchexecute` ของ Flow ตรงๆ — payload อ่านไม่ออกและเป็นสัญญาณบอทชัดที่สุด (3) ใช้บัญชีหลัก — ถ้าโดนแบนเสียทั้งเครดิต Ultra และงานที่ทำมือ

**ผลที่ยอมรับ:** หน้าเว็บเปลี่ยนเมื่อไหร่บอทพังที่ selector (แก้ที่ `worker/flow-selectors.ts` ไฟล์เดียว) · หน้าต่าง Chrome ต้องเปิดค้างและห้ามย่อ · โปรไฟล์เปิดได้ทีละโปรเซส สคริปต์ทดสอบที่ใช้ Flow จริงต้องหยุดบอทก่อน · โปรเจกต์ใน Flow เป็นของบัญชีสำรอง เปิดในเบราว์เซอร์บัญชีหลักไม่ได้ (ปุ่มในหน้า `/flow` เปิด Brave โปรไฟล์บัญชีสำรองแทน) · พังแล้วหยุดทั้งคิว ไม่ลองซ้ำเอง เพราะการยิงซ้ำใส่หน้าที่พังคือสัญญาณบอทที่ชัดที่สุด
